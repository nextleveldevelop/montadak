1) نظرة عامة

منتداك سكريبت منتديات عربي مكتوب بـ PHP (بدون إطار عمل) مع قاعدة بيانات MySQL / MariaDB، بواجهة عربية من اليمين لليسار ووضع داكن وتصميم متجاوب.

البندالقيمة (من الملف المرفق)
عدد الملفات88 ملفًا، منها 70 ملف PHP و4 ملفات JavaScript وملف CSS واحد (نحو 9.7 ألف سطر)
أكبر ملفات الشيفرةincludes/functions.php (1764 سطرًا) ثم thread.php (552) ثم install.php (515) ثم includes/extras.php (513)
المتطلباتPHP 7.4+ مع mysqli وmbstring وjson وsession (وgd وfileinfo موصى بهما لرفع الصور)، وMySQL 5.6+ / MariaDB 10.1+ بمحرك InnoDB، وخادم Apache يدعم .htaccess
التثبيتمعالج install.php بأربع خطوات، يقفل نفسه ويحذف نفسه بعد النجاح
الأيقوناتHeroicons (رخصة MIT) — الرخصة في assets/ICONS-LICENSE.txt
المكتبات الخارجيةمحرر النصوص Quill 1.3.7 فقط (يُحمّل من CDN)؛ كل الرسوم البيانية SVG مولّدة من PHP

2) بنية المشروع

montadak/
├── index.php, forum.php, thread.php, profile.php ...   ← صفحات الواجهة (جذر المشروع)
├── admin/            ← لوحة الإدارة (المنتديات، الأعضاء، الإحصائيات، الإعدادات، الوسوم ...)
├── includes/         ← القلب: bootstrap, db, functions, layout, notify, extras, icons
├── assets/           ← css/style.css  |  js/ (app, sidebar, editor, messenger)  |  images/
├── config/           ← config.php (يُنشأ بالتثبيت) + config.sample.php + حماية .htaccess
├── install/          ← schema.sql (هيكل قاعدة البيانات) + حماية .htaccess
├── install.php       ← معالج التثبيت
├── robots.php, sitemap.php   ← يولّدان robots.txt و sitemap.xml ديناميكيًا
└── .htaccess         ← إعادة الكتابة + منع الوصول للملفات الحساسة

المبدأ المعماري: كل صفحة تشغّل منطقها أولًا (قراءة/كتابة/تحويل) ثم تستدعي page_header() ... page_footer()، لذلك تحدث كل عمليات التحويل قبل إرسال أي HTML. ملفات includes/ لا تطبع شيئًا بنفسها.

3) شرح الملفات

أ) النواة — includes/

الملفوظيفته
bootstrap.phpيُحمَّل أول كل صفحة: يتحقق من وجود الإعدادات (وإلا يحوّل لـ install.php)، ويحمّل الإعدادات والمكتبات، ويبدأ الجلسة بإعدادات آمنة، ويرسل الترويسات الأمنية، ويشغّل ترقيات الجداول التلقائية. يعرّف ثوابت مثل 20 موضوعًا و15 ردًا في الصفحة، ونافذة المتصل 5 دقائق، وحد المشاركة 20000 حرف.
db.phpغلاف صغير لـ mysqli: كل استعلام Prepared Statement (دوال db_all وdb_row وdb_val وdb_exec وdb_transaction) ويدعم المنفذ المخصص.
functions.phpأكبر ملف: دوال الصلاحيات والأدوار، حماية CSRF، تنقية HTML للمحرر (القائمة البيضاء)، رتب العضو، الترقيم، تنسيق التواريخ، الحظر والكتم، سياسة كلمة السر، إعدادات الموقع، وroبوتس وخريطة الموقع.
layout.phpهيكل الصفحة: الترويسة والشريط الجانبي والتذييل، جدول المواضيع، قائمة خيارات الموضوع، تنقل لوحة الإدارة، وترويسة الصفحات page_hero().
notify.phpالإشعارات ونظام المتابعة، وجداول الإشعارات والمتابعات والحظر في منتدى معين وسجل الإشراف والترشيحات، وإنشاء «المنتدى الإشرافي» لكل قسم تلقائيًا.
extras.phpالحفظ (المحفظة)، عدّاد المشاركات، المنشورات القصيرة (المواضيع الصغيرة) وإعجاباتها ومشاركاتها، وسوم المنشورات ومتابعتها، خلفية العضوية ورفعها بأمان، شكل الصفحة الرئيسية، خوارزمية التفوق، وصيغة المؤنث (مشرفة، مديرة ...).
icons.phpمجموعة أيقونات Heroicons تُطبع مرة واحدة في الصفحة (SVG sprite) ويُستدعى منها icon('home').

ب) الصفحات العامة وصفحات الأعضاء

الملفوظيفته
index.phpالصفحة الرئيسية: جدول الأقسام والمنتديات (مع قفل ظاهر للمنتدى المقفول وأيقونة المشرفين)، وعمود «من صفحات الأعضاء» للمنشورات القصيرة. الإدارة تختار: الجدول فقط / المنشورات فقط / الاثنان.
forum.phpصفحة المنتدى: ترويسة (أيقونة، اسم، وصف، المشرفون)، شريط أدوات (موضوع جديد، متابعة، بريد المنتدى، إدارة، الانتقال لمنتدى آخر) وجدول المواضيع بأيقونات.
thread.phpصفحة الموضوع: المشاركات والردود، صندوق معلومات الكاتب (الرتبة، النجوم ونسبة التفوق، المتابعون)، الإعجاب والحفظ والمشاركة والتبليغ والاقتباس والإخفاء، الاستفتاء، وأدوات الإشراف.
new_thread.php / edit_post.phpإنشاء موضوع (مع استفتاء اختياري) وتعديل مشاركة أو رد.
profile.phpصفحة العضوية: غلاف وخلفية، صورة، إحصائيات (مشاركات، متابعون، يتابع)، نجوم التفوق، النبذة، بيانات اختيارية الظهور، آخر المواضيع، المنشورات القصيرة، وشريط أدوات الإشراف.
members.php / online.phpقائمة الأعضاء بجدول احترافي وبحث وترتيب (30 في الصفحة)، وقائمة المتواجدين الآن مع قواعد الإخفاء (15 في الصفحة).
search.phpبحث متقدم: كلمات، كاتب الموضوع، منتدى، العناوين فقط أو النص الكامل.
tag.php, mini.phpصفحة الوسم، وعرض/إنشاء/تعديل/حذف المنشور القصير (أقل من 300 كلمة).
register.php, login.php, logout.phpالتسجيل (مع اختيار الجنس الذي لا يتغير)، الدخول مع تحديد المحاولات، والخروج.

4) المزايا حسب المجال

المنتدى والمحتوى

  • أقسام ومنتديات برمجية الترتيب، أيقونة أو صورة لكل منتدى، قفل المنتدى من الإدارة مع علامة قفل ظاهرة.
  • مواضيع وردود، تثبيت وقفل وإخفاء ونقل، واستفتاءات (اختيار واحد أو متعدد).
  • إعجاب وحفظ ومشاركة وتبليغ واقتباس.
  • حدود مشاركة يومية لكل منتدى، وحماية من الإغراق عبر منع الكتابة المؤقت.
  • بحث متقدم، وخريطة موقع وrobots.txt مضبوط للـ SEO.

المحرر

  • تنسيق كامل (عناوين، ألوان، قوائم، اقتباس، شيفرة، روابط، اتجاه RTL/LTR).
  • صور مرفوعة بحماية، وتحجيمها داخل المحرر.
  • فيديو يوتيوب يظهر مشغّلًا داخل النص.
  • جداول احترافية بألوان وإطارات قابلة للتعديل بعد الإدراج.
  • تراجع وإعادة، وتغيير حجم النص، ومعاينة قبل النشر.

الأعضاء والتواصل

  • صفحة عضوية بتصميم جديد: غلاف قابل للتخصيص (1200×300)، إحصائيات، نبذة، بيانات اختيارية الظهور.
  • الجنس يُحدد عند التسجيل ولا يُعدل، ويُطبَّق المؤنث تلقائيًا (مشرفة، مديرة، متصلة الآن، عضوة جديدة).
  • متابعة الأعضاء والمنتديات والمواضيع والوسوم، وإشعارات فورية.
  • رسائل خاصة، ومحادثة فورية، وبريد المنتدى، ومنع المراسلة، وإخفاء التواجد بقواعد متدرجة حسب الرتبة.
  • المحفظة الشخصية: حفظ المواضيع والردود والمنشورات القصيرة.
  • المنشورات القصيرة بوسوم: تظهر في صفحة العضوية وفي الصفحة الرئيسية، مع إعجاب وحفظ ومشاركة وعدّادات.
  • تقييم العضو بنجوم ونسبة تفوق (القسم 8).

الإشراف والإدارة

  • رتب: مدير (مالك رقم 1)، نائب مدير، مشرف لكل منتدى، عضو.
  • تحذير وكتم (منتدى، مجموعة منتديات، أو الكل للمدير)، وسجل عقوبات حالية وسابقة.
  • ترشيح المشرفين بموافقة المدير، وطلب قفل العضوية.
  • إحصائيات مرئية وفلاتر متقدمة وإعدادات الموقع وإدارة الوسوم.

5) الأدوار والصلاحيات

الرتبةأهم الصلاحيات والقيود
زائرقراءة المنتديات المفتوحة للجميع؛ لا يرى عمود الخيارات في جدول المواضيع.
عضوكتابة المواضيع والردود وتعديل/حذف ما كتبه هو، الحفظ والمتابعة والمراسلة والمحادثة، نشر منشورات قصيرة، وتخصيص صفحته.
مشرف (لكل منتدى)تثبيت وقفل وإخفاء المواضيع والردود ونقلها، التحذير والكتم في منتدياته فقط، الترشيح للإشراف وطلب قفل العضوية، ويرى المنتدى الإشرافي لقسمه. لا يحذف محتوى غيره ولا يعدّل إعدادات المنتدى.
نائب المديربصلاحيات المدير تقريبًا، لكنه لا يصبح المدير الأصلي ولا يأخذ مكان العضو رقم 1، ولا يرقّي نوابًا.
المدير (رقم 1)كل شيء: حذف أي موضوع أو رد أو منشور، قفل العضويات، تعيين وإزالة المشرفين، ترقية النواب، الكتم في كل المنتديات، وإدارة الإعدادات والوسوم.
المدير والمشرف لا يُقيَّمان بالنجوم. والمدير يستطيع مراسلة أي عضو حتى لو منعه.

إخفاء التواجد: العضو العادي المخفي يراه المشرفون والمدير ونائبه؛ المشرف المخفي يراه المدير ونائبه فقط؛ المدير المخفي يراه المدير الآخر ونائبه فقط؛ والعضو يرى نفسه دائمًا.

7) الحماية والأمان

  • حقن SQL: كل الاستعلامات Prepared Statements عبر db.php.
  • CSRF: رمز لكل نموذج POST والتحقق بـ hash_equals.
  • XSS: الإخراج بـ e() لكل ما يدخله المستخدم، ومحتوى المحرر يمر على منقٍّ بقائمة بيضاء (وسوم وسمات محددة، وتنقية أنماط الجداول، وصور موقعك فقط، ويوتيوب فقط يُعاد بناؤه من المعرّف).
  • كلمات السر: password_hash، وسياسة 10 أحرف على الأقل بحروف وأرقام ورموز.
  • الجلسات: كوكي HttpOnly وSameSite، وإعادة توليد المعرّف عند الدخول، وتحديد محاولات الدخول.
  • الرفع: فحص النوع الحقيقي، حد الحجم والأبعاد، إعادة ترميز بـ GD، أسماء عشوائية، ومنع تنفيذ PHP في مجلدات الصور بـ .htaccess.
  • ترويسات: سياسة CSP، ومنع الإطارات (X-Frame-Options)، ومنع تخمين النوع (nosniff)، وسياسة المُحيل.
  • الملفات الحساسة: config/ وinstall/ وincludes/ محجوبة عن الويب، ومعالج التثبيت يقفل نفسه.
  • الخصوصية: تُخزَّن عناوين IP مبتورة (الجزء الأول فقط).
  • الصلاحيات: التحقق من الرتبة داخل ملفات التنفيذ نفسها (مثل sanction.php وmoderate.php) وليس في الواجهة فقط.
هذه قراءة وبحث في الكود وليست اختبار اختراق حقيقيًا. يوصى بفحص أمني مستقل قبل الإطلاق.

8) خوارزمية التفوق (تقييم العضو بالنجوم)

الدالة: member_rating($uid) في includes/extras.php، ويعرضها rating_html() في صفحة العضوية وتحت اسم الكاتب في صفحة الموضوع. الناتج: نجوم من 0 إلى 10 ونسبة تفوق من 0 إلى 100%.

أولًا: من يُقيَّم ومن لا يُقيَّم

  • المدير ونائبه (role = admin) والمشرفون (في أي منتدى): لا يُقيَّمون (الدالة تعيد null ولا تظهر نجوم).
  • العضو العادي فقط يُحسب له التقييم.

ثانيًا: المدخلات الستة

ثالثًا: المعادلة

لكل مدخل تُحسب نسبة تقدمه نحو هدفه بمنحنى «عوائد متناقصة» (الجذر 0.4)، فأول الإنجازات تُكافأ أكثر، ثم يبطؤ الصعود:

p(x, target) = min( 1 , (x / target) ^ 0.4 )

score = 0.35·p(T,500) + 0.08·p(R,1000) + 0.25·p(L,500)
      + 0.12·p(S,150) + 0.08·p(H,100)  + 0.12·p(F,200)

pct   = floor( score × 100 )          // 0 .. 100
stars = floor( pct / 10 )             // 0 .. 10

سادسًا: ملاحظات على الخوارزمية

  • خلل حسابي صغير: عند بلوغ كل الأهداف تمامًا يجب أن تكون النسبة 100%، لكن جمع الأوزان بالأعداد العشرية قد يعطي 0.9999999 فيُقرّب floor الناتج إلى 99%. فعمليًا قد لا يظهر 100% أبدًا. الحل: floor($score * 100 + 1e-9) أو round. أنبّه إليه لأنني لاحظته عند محاكاة الصيغة (الحالة 600/1200/500/150/100/200 أعطت 99%).
  • التقييم يُحسب لحظيًا من قاعدة البيانات في كل عرض (مع تخزين مؤقت داخل الطلب الواحد فقط): دقيق، لكنه يضيف نحو 7 استعلامات لكل كاتب في صفحة الموضوع. إن كبر المنتدى، يُفضل تخزين النتيجة وتحديثها دوريًا.
  • الإعجابات المحسوبة تشمل إعجابات المواضيع والردود والمنشورات القصيرة؛ وحذف المحتوى المخفي يخفض T وR.

9) الرتب حسب عدد المشاركات (نظام منفصل)

الدالة rank_info() في functions.php تعطي عنوان رتبة حسب مجموع مشاركات العضو (مواضيع + ردود)، وهي مستقلة عن خوارزمية التفوق. لا تظهر لها نجوم الآن (الدالة stars_html أُوقفت)، ويظهر عنوان الرتبة فقط في صفحة العضوية للأعضاء العاديين (وليس للإدارة والمشرفين).

10) ملاحظات تقنية ومقترحات

  • تنظيف قاعدة البيانات: حذف الجداول القديمة غير المستخدمة (القسم 6) بعد نسخ احتياطي.
  • تنظيف CSS: قسم LEGACY في آخر style.css (نحو 161 قاعدة) غير مستخدم ويمكن حذفه بعد التجربة.
  • أداء: تخزين نتيجة التفوق (انظر القسم 8)، وإضافة فهارس إن كبر عدد المواضيع.
  • الاعتماد على CDN: محرر Quill يُحمّل من CDN؛ لاستقلال تام يُنزَّل محليًا ثم يُعدَّل CSP.
  • الاختبار: السكريبت بحاجة إلى اختبار تشغيلي حقيقي (تثبيت، تسجيل، نشر، صلاحيات) على نسخة تجريبية؛ لم أستطع تشغيل PHP أثناء إعداد النسخ.
  • خريطة الموقع وroبوتس: إذا ثُبّت المنتدى في مجلد فرعي، يقرأ محرك البحث robots.txt من جذر الدومين فقط، فأضف هناك سطر Sitemap يدويًا.
